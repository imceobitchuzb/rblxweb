# ROXIE HUB — Screenshot Placeholders

To capture UI screenshots for this portfolio repository:

1. Start development server: `npm run dev`
2. Navigate to `http://localhost:3000`
3. Capture the following screens and place them in this directory:
   - `landing.png` — Marketing Landing Page (`/`)
   - `dashboard.png` — Executive Creator Dashboard (`/dashboard`)
   - `ideas.png` — Ideas Studio with Kanban and Grid views (`/ideas`)
   - `characters.png` — Character Roster & Dossiers (`/characters`)
   - `scripts.png` — Screenplay Studio with Scene Timeline (`/scripts`)
   - `videos.png` — Video Studio Pipeline (`/videos`)
   - `calendar.png` — Multi-platform Publishing Calendar (`/calendar`)
   - `analytics.png` — Creator Intelligence & Multi-Channel Performance (`/analytics`)
   - `command-palette.png` — Keyboard Command Palette modal (`Ctrl+K`)
   - `global-search.png` — Multi-entity Global Search modal
